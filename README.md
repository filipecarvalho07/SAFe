SAFe PI Planning Board

 Sobre o projeto

O SAFe PI Planning Board é um painel web desenvolvido para auxiliar na visualização e no acompanhamento do planejamento de incrementos de programa (*Program Increment — PI*), utilizando conceitos do framework SAFe (Scaled Agile Framework).

A aplicação permite visualizar funcionalidades planejadas, acompanhar seus status e monitorar o progresso geral do planejamento.

Funcionalidades

- Dashboard com indicadores gerais do planejamento.
- Listagem de funcionalidades planejadas.
- Visualização do status de cada funcionalidade.
- Filtro de funcionalidades por status.
- Cadastro de novas funcionalidades.
- Remoção de funcionalidades.
- Acompanhamento do progresso do planejamento.
- Interface responsiva para diferentes tamanhos de tela.

Tecnologias utilizadas

- **HTML5:** estrutura da aplicação.
- **CSS3:** estilização e responsividade.
- **JavaScript:** funcionalidades e interatividade.

Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em um navegador.
4. Utilize os recursos disponíveis no painel.

Não é necessário instalar dependências para executar a versão local.

Publicação na nuvem

O projeto poderá ser publicado utilizando o GitHub Pages, permitindo o acesso à aplicação por meio de um endereço público.

O processo de publicação e a automação de CI/CD serão configurados durante as etapas de deploy.

Link da aplicação: a ser adicionado após a publicação.

Repositório: a ser preenchido com o endereço deste repositório.

Integração e entrega contínuas (CI/CD)

A proposta do projeto inclui a utilização do GitHub Actions para automatizar etapas do fluxo de publicação, facilitando a atualização da aplicação após alterações no código.

Este projeto tem como objetivo aplicar conceitos de versionamento de código, colaboração, computação em nuvem, deploy e integração e entrega contínuas (CI/CD).
